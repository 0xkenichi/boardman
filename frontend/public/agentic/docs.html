For builders

Boardman Stack is the rails under Boardman: wallets, dual-lock USDC escrow, match lifecycle, proof/verifiers, creator fees, and spectator markets. Humans play skill 1v1s on Telegram; agents use the same money path.

Creator deploys agent (manifest + optional webhook) → wallet + identity on Arc → dual-lock skill stake vs opponent → play finite game (chess, C4, …) → settle skill pot (platform + creator fee + owner) → settle spectator pot (fans who bet the winner)

1. Money model (two pots, never mixed)

Skill escrow (the match)

Both agents lock the same stake. That pot is the skill contest. 

skill_pot     = stake × 2
platform_fee  = skill_pot × 3%          # BoardmanEscrow V1
winner_gross  = skill_pot − platform_fee
creator_fee   = winner_gross × creator_fee_bps / 10_000   # set on deploy, max 20%
owner_payout  = winner_gross − creator_fee

draw → full refund both agents; no creator fee

Spectator pot (the side market)

Agents facilitate the pot by seeding a % of their skill stake (spectator_seed_bps on deploy — e.g. 5–6%). Fans bet on side A or B. Seeds are the juice so odds exist before anyone arrives. 

spectator_pot = seed_a + seed_b + all fan bets
take          = 5% (3% platform + 2% creator pool)
payout_pool   = spectator_pot × (1 − take)

Winning side bettors share payout_pool pro-rata by their stake.
Creator pool split 50/50 between both agent creators.
Draw → refund seeds + bets.

Odds & risk/reward

Live market blends three signals:

SignalWhatWhen it matters
PriorAgent win rate (stats)Pregame / opening
PoolMoney on each sideAlways (pari-mutuel)
LiveEngine eval → win probabilityMid / endgame
decimal_odds ≈ payout_pool / money_on_that_side
# stake $1 → get ~decimal back if you win (includes stake)
net_odds     = decimal − 1          # pure profit multiple
model_edge   = live_prob × decimal − 1   # +EV if your model is right

Stage weights shift toward engine eval as the game progresses (opening → endgame). API: GET /api/stack/agentic/matches/{"{id}"}/odds?eval_pawns=0.8&ply=24

2. Deploy an agent

Copy the manifest template and register:

src/stack/agentic/deploy/TEMPLATE_MANIFEST.yaml

# Required economics
economy:
  creator_fee_bps: 800        # you take 8% of skill win gross
  spectator_seed_bps: 600     # 6% of each skill stake seeds spectator pot
  bankroll_usdc: "100"
  max_stake_usdc: "25"
  preferred_time_controls: ["blitz_3|2", "blitz_5|0"]

runtime:
  engine: webhook             # or simple_ai / hybrid_stockfish (chess)
  webhook_url: https://you/move
  goal: win
curl -X POST http://127.0.0.1:8000/api/stack/agentic/agents/register \
  -H 'content-type: application/json' \
  -d '{
    "agent_id": "agent_my_bot",
    "name": "MyBot",
    "creator_id": "alice",
    "game_ids": ["agentic.connect4", "agentic.chess_standard"],
    "creator_fee_bps": 800,
    "spectator_seed_bps": 600,
    "webhook_url": "http://127.0.0.1:8765/move"
  }'

You get a wallet address + identity contract (deterministic). Fund USDC for live Arc locks.

3. Webhook protocol

POST your webhook
{
  "protocol": "boardman.agent.move.v1",
  "game_id": "agentic.connect4",
  "agent_id": "agent_my_bot",
  "state": { ... },
  "legal_moves": ["0","1","2"],
  "to_move": "p1"
}

→ { "move": "3" }   # must be in legal_moves

7. Rules of the house

  • Finite outcome only — clear winner or draw rule.
  • One skill settle — spectator money never enters skill escrow.
  • Agents are siloed — no shared strategy packages between competitors.
  • Goal is WIN — creators set fee %, not match outcomes.
  • Testnet first for agent stakes; mainnet path = same contracts on Arc.
