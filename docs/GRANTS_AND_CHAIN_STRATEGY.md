3. **Stack loyalty** (their wallets, their stablecoin, their L1)  
4. **Distribution** (users outside crypto Twitter — NG game centers is gold)  
5. **Milestones** you can hit in 30–90 days  

Rematch’s unfair advantages to write into every application:

- **Real settlement:** dual-lock USDC escrow, not points-only  
- **Circle-native:** developer-controlled wallets + USDC

- **Emerging markets:** Nigeria game centers + Telegram  
- **AI mediation:** screenshot vision for fair play

## 7. Using the $PLAY airdrop to drive bot + chain volume

From `TOKENOMICS_PLAY.md`: points ≠ token 1:1. Use that as a **growth lever** chains will like.

### 7.1 Rules that push the right behavior

| Behavior we want | Airdrop weight boost |
|------------------|----------------------|
| **Settled match** (dual lock + resolve) | Highest weight |
| Settled **on preferred chain** (Arc week / AVAX week) | Chain multiplier (e.g. 1.5×) |
| FT **screenshot + AI conf ≥ 0.75** | Bonus |
| **Public board** match | Bonus |
| Referred user first settle (centers) | Partner + user bonus |
| Cancel / no dual lock | Zero or negative |
| Same two wallets farming | Cap / ban |

### 7.2 Seasonal “chain quests” (grant theater + real volume)

Run in bot:

1. **Arc Season** — “All Arc settles earn 2× airdrop weight this month”  
2. **Avalanche Push** — same for Fuji then mainnet  
3. **Base Weekend** — consumer onboarding  

Publish leaderboard + weekly stats → perfect **grant progress reports**.

### 7.3 Claim on the chain you want to promote

- Testnet claim contract **on Arc** first → forces Arc wallets + Arc txs  
- Optional secondary claim on Base for reach  
- Message: “Claim test $PLAY on Arc — points stay; this is not 1:1”

### 7.4 Funnel (simple)

```
Telegram /start (optional partner QR)
  → fund USDC on chosen chain
  → 1v1 lock (only settled matches count)
  → earn PLAY points + airdrop weight
  → season end → claim $PLAY (testnet)
  → (later) mainnet eligibility from testnet seasons
```

### 7.5 What not to do

- Don’t pay airdrop for mere wallet create  
- Don’t 1:1 convert points → infinite supply  
- Don’t hide that test $PLAY has no cash value
