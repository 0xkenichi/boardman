# 1v1 result screens by game (what proof should look like)

Reference for Rematch proof + AI hints. Built from public screenshots, App Store/store pages, wikis, Reddit, and video UI.

**Reporting model (always):**

| `outcome_type` | Player claims | Proof photo |
|----------------|---------------|-------------|
| `binary_winner` | In-game name + **I won / I lost** | Final winner / victory / defeat UI |
| `scoreline` | HOME/AWAY + **home-away** numbers (e.g. `5-3`) | Full-time / box score with both totals |

**How to use image links:** Open the reference URLs in a browser — they show the real end UI (or a close public equivalent). Rematch cannot host copyrighted game art; these are research bookmarks for ops + AI-hint writing.

## iMessage / GamePigeon

**Shared look:** Cartoon board **inside the iMessage bubble/thread** (not a full-screen console broadcast). End states usually show **You Win / You Lose**, a winner banner, or **two score totals**. UI is flat 2D, game sits in Messages.

| Game | Outcome | What the final looks like | Public refs |
|------|---------|---------------------------|-------------|
| **8 Ball** | Win/lose | Flat cartoon pool table in chat; after 8-ball pot, win/lose state on the bubble. **Not** Miniclip 3D avatars. | [WikiHow play guide (UI steps)](https://www.wikihow.com/Play-8-Ball-on-iMessage); [GamePigeon App Store](https://apps.apple.com/us/app/gamepigeon/id1124197642); [YouTube: play 8 Ball on iMessage](https://www.youtube.com/watch?v=IWfTDR9EbGY) |
| **Basketball** | Scoreline | Two player point totals after last shot | Same App Store + GamePigeon basketball clips |
| **Archers / Darts / Mini Golf** | Scoreline | Points or strokes for both; final totals, not mid-arrow | App Store feature list: Archery, Darts, Mini Golf |
| **Anagrams / Word Hunt** | Scoreline | Both players’ **points** after timer; often SCORE + word count | [Word Hunt tutorial (scores on screen)](https://www.youtube.com/watch?v=cMkGuU0NZbs); Instagram/TikTok Word Hunt final scores (e.g. 6600-style totals) |
| **Checkers / 4 in a Row / Cup Pong / Sea Battle** | Win/lose | Board ends with **You Win** / last piece / fleet gone | GamePigeon list on App Store |
| **Chess** | Win/lose | Checkmate / resign; chat may show **I lost** / win messaging (known quirks on stalemate) | [Reddit: iMessage chess “I lost” UI](https://www.reddit.com/r/mildlyinfuriating/comments/5kdxgc/this_imessage_chess_game_telling_me_i_lost_when/); [r/GamePigeon win/lose threads](https://www.reddit.com/r/GamePigeon/) |

**Accept:** Final bubble with win/lose or both scores.  
**Reject:** Mid-shot aim only, empty table, no end banner.

## What Rematch should **never** accept as sole proof

- Mid-game HUD only (no final banner / no FT)
- Battle Royale placement / “#12” / Booyah list without a **duel** victory
- Lobby / loadout / shop / XP-only / Pass progress
- Someone else’s stream with different gamertags than claimed
- Same in-game name claimed by both players

## Fair ruling stack (random users)

1. **Catalog** — `outcome_type` + `result_screen` + `ai_hints` (per game)  
2. **Interview** — photo → **in-game name** (binary) → side if needed → W/L or scoreline → confirm  
3. **Dual report** — auto-pay only if reports **agree** (and names differ)  
4. **AI** (optional, needs vision API key) — read Winner/FT; cross-check name under Winner  
5. **Dispute** — if both claim win or names collide  

### Example: 8 Ball Pool (Finch case)

| Step | stillkenichi | Opponent |
|------|--------------|----------|
| Photo | VS + gold **Winner** over Finch | Same style end screen |
| Name | `Finch` | `Emmanuella` |
| Claim | **I won** | **I lost** |
| Result | Agree → payout stillkenichi | |

If both type `Finch` or both tap **I won** → **no auto-pay**.

## Catalog maintenance

When you capture a new real final screen:

1. Drop notes into `config/games/*.yaml` → `result_screen` + `ai_hints`  
2. Restart bot (catalog is cached)  
3. Prefer 2–3 bullet hints from the real UI (banner text, layout left/right)  
4. Optionally paste a private ref path (ops only; don’t commit player PII)

See also: `docs/PROOF_BY_GAME.md`.
