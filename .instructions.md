# Project Instruction File

This repository is the standalone Rematch checkout at `/Users/kenichi/Documents/reMatch/rematch`.

The code is intended to run locally from repo root with `src/` package layout. Many deployment scripts and docs still reference a larger upstream monorepo package path (`gaming.src.*`), but local troubleshooting should use the standalone local paths unless the environment explicitly provides a `gaming` package root.

Rules for Copilot in this workspace:

- Prefer `python3` and the repository virtual environment at `./.venv/bin/python` for local commands.
- Do not assume a global `python` command exists. If `python` is missing, recommend `python3` instead.
- For this local checkout, use these startup commands from repo root:
  - `./.venv/bin/python -m pip install -r src/backend/requirements.txt`
  - `./.venv/bin/python -m src.bot.main`
  - `./.venv/bin/python -m uvicorn src.backend.main:app --host 0.0.0.0 --port 8000`
- If `./.venv/bin/python` is unavailable, fallback to:
  - `python3 -m pip install -r src/backend/requirements.txt`
  - `python3 -m src.bot.main`
  - `python3 -m uvicorn src.backend.main:app --host 0.0.0.0 --port 8000`
- Use relative repo paths and concrete commands in fenced code blocks. Example:
  ```bash
  cd /Users/kenichi/Documents/reMatch/rematch
  ./.venv/bin/python -m src.bot.main
  ```
- The frontend route `/rematch/leaderboard` loads data from `/api/rematch/public`. When a user reports that page is down, verify `frontend/app/rematch/leaderboard/page.tsx` and `src/backend/main.py` (router registration) before answering.
- If a backend endpoint is missing, prefer adding a minimal implementation and registering it in the FastAPI app rather than only explaining the missing route.
- Keep responses concise, action-oriented, and avoid unnecessary phrasing.
- When troubleshooting package install failures, mention proxy/network access issues if pip cannot fetch dependencies and suggest fixing them before rerunning installs.
- If deployment docs reference `gaming.src.*`, note that this is for the larger monorepo/container environment; for local standalone work, use `src.*` paths.
