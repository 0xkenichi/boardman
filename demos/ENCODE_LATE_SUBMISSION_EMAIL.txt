2. SUBMISSION DETAILS
────────────────────────────────────────

What we built
-------------
Boardman is programmable-money infrastructure for finite-outcome skill contests on Arc,
using USDC as the unit of account.

We ship TWO layers on the same settlement rails:

A) HUMAN ↔ HUMAN (Telegram)
   • Official bot: t.me/myboardmanOfficialBot
   • Community / public challenge room (Telegram group): post open challenges;
     others can claim (fastest fingers / open matchmaking)
   • Private 1v1: challenge a friend directly in Telegram → accept
   • Get USDC / fund wallet → dual-lock stake (BoardmanEscrow on Arc testnet)
   • Play real skill game (console-first path) → submit full-time photo proof
   • AI-assisted outcome path → winner paid from escrow
   • Product loop: Lock in. Play. Settle. Run it back.

B) AGENTIC ECONOMY (Boardman Stack)
   • Autonomous agents with wallets, bankrolls, and stake policies
   • Reference agents Raja (attack) vs Nero (defense) — chess first
   • Equal skill-stake negotiation from free capital (unequal bankrolls bind stake)
   • Separate spectator pot: agents seed a % of stake; fans bet for/against
   • Live odds, pot cap, mid-game freeze
   • Creator fees on skill wins; platform fee aligned with escrow (~3%)
   • LP role: top up agent bankroll for a share of net skill profit
   • Multi-game catalog + builder path (manifests, webhooks, developer docs)
   • Optional free LLM strategy layer (ASI / Gemini) amplifies each builder’s mind

Why this is programmable money on Arc
--------------------------------------
• USDC-native stakes, fees, seeds, and spectator pots
• Humans and agents share the dual-lock skill escrow primitive
• Skill escrow and spectator markets are deliberately separate ledgers
• Creator + LP economics make deployers and backers first-class actors

Process
-------
• Human Telegram product first (where skill stakes already live in chat)
• Then agentic layer on Boardman Stack reusing the same money story
• Chess as the reference finite-outcome game for agents
• Economics audited (fees, seeds, negotiation, pot caps, LPs)
• Live site + public repo for judges
